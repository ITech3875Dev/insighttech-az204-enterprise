## Conventions
- Learning paths: `az204-lpXX-<topic>`
- Modules: `mXX-<topic>`
- Labs: `labs/beginner`, `labs/intermediate`, `labs/advanced`, `labs/capstone`
- Assessment: `exams/practice-50q.md`, `exams/answer-key.md`
- Validation: `validation/az204-lpXX-validate.ps1`

## Transition Model
- Existing broad AZ-204 tracks are archived under `learning-paths/legacy-az204-broad/` for migration reference.
- Canonical path set above is the source of truth for all new work.
- Legacy AZ-104 material is archived under `learning-paths/legacy-az104/`.
